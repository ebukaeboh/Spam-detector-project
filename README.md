# Spam Detector Project

Detects spam messages using Python & Machine Learning.

### What it does
- Takes a message / email text
- Predicts: Spam or Not Spam
- Helps filter unwanted and scam messages

### How it works
1. Dataset of spam and ham (not spam) messages
2. Clean the text — remove stopwords, punctuation
3. Convert text to numbers with TF-IDF
4. Train a Machine Learning model with Python
5. Test with new messages

### Tech Used
Python | Machine Learning | NLP | scikit-learn | Git & GitHub

### How to Run
1. Clone this repo
2. Install requirements: pip install -r requirements.txt
3. Run the Python file / notebook
4. Type a message to test if it is spam or not
